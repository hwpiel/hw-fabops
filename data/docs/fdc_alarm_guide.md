# FDC(Fault Detection & Classification) 알람 대응 가이드

FDC는 설비 센서 데이터를 실시간 모니터링해 이상을 조기 감지한다.

알람 등급
- Warning: 관리 상한 근접. 트렌드 관찰.
- Alarm: 관리 상한 초과. 로트 홀드 검토.
- Interlock: 즉시 설비 정지.

대표 신호별 대응
- peak_temp 상향 트렌드(RTP): 파이로미터 캘리브레이션 이력 우선 확인.
- 빔 전류 불안정(Implant): 소스 상태·도즈 모니터 확인.
- 파티클 급증(Deposition): 챔버 세정 주기 점검.

원칙
- 단일 시점보다 트렌드와 대조 설비 편차로 판단.
- 알람-품질(계측/수율) 연계 분석으로 근본 원인 규명.
